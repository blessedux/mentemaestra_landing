# Landing content plan — boutique studio positioning

**Goal:** Align [mentemaestra.studio](https://www.mentemaestra.studio/) with a sharp, premium boutique studio (Basement / Happy Pizza–style): clear offers, curated proof, outcome-first narrative—not a generalized “everything creative” subscription shop.

**Reference direction:** Brand + launch-site projects, selective retainers; 3–4 productized offers; international founders.

---

## 1. Positioning & first impression (hero)

**Current gap:** Hero reads Designjoy-like (broad digital presence + continuous design). Studio vision is branding + launch sites + selective retainers.

**Actions:**

- [ ] Replace hero headline/subhead with a boutique line, e.g. “Estudio digital para founders que quieren marcas y productos que conviertan,” plus one line that limits scope: branding + product + launch sites—not “all creative services.”
- [ ] Name **for whom** (fintech, devtools, startups, etc.) and **what you specialize in** above the fold.
- [ ] Remove or drastically reduce the repeated block (“WEB, PRODUCTO Y MARCA / … / TODAS TUS NECESIDADES…”)—it reads bloated and generic; replace with one tight value line or a single structured row.

---

## 2. Narrative & story flow

**Current gap:** Service-first, feature-heavy; strongest line is buried; stats at “0” erode trust.

**Actions:**

- [ ] Reorder story to: **who it’s for** → **problems** (weak brand, confusing product, low-conversion site) → **your way** (strategy → design → build → focused support) → **proof** (3–6 cases with outcomes).
- [ ] Elevate the line about interfaces reflecting craft and clarity so customers grasp value at a glance—use as narrative anchor (hero or early section).
- [ ] **Stats:** Hide counters until real numbers exist, or replace with truthful framing (“+X proyectos,” “desde 2022,” etc.). Fix contradiction with “Estudio recomendado desde 2022.”
- [ ] Tighten “Diseño bajo demanda” toward something ownable (e.g. “Estudio de diseño en ritmo con tu negocio”) if it stays.

---

## 3. Services & value proposition

**Current gap:** Huge horizontal list; sounds like “we do everything”; subscription language mismatches boutique + project reality.

**Actions:**

- [ ] Replace service-cloud with **3–4 named offers**, each with: for whom / when, outcomes (clarity, conversion, fundraising story), CTA (“Ver paquete,” “Cotizar este servicio”).
- [ ] Suggested bundle: **Brand Sprint**, **Launch Website**, **Design Partner** (retainer), optional **vertical** (e.g. fintech-special).
- [ ] Core: Branding / Web / Product. Move contenido, video, foto, redes to **Growth add-ons** or a **qualified-leads-only** page.

---

## 4. Pricing & model alignment

**Current gap:** Homepage feels subscription-first; project pricing feels secondary; hybrid model unclear.

**Actions:**

- [ ] Make **project offers** (Brand Sprint + Launch Website) the primary entry; position subscriptions as “socio continuo” / retainer with **explicit capacity** (e.g. “Solo 2 cupos activos”).
- [ ] On Precios, tie each price to a **named offer** and short narrative—not a flat menu.

---

## 5. Portfolio presentation

**Current gap:** Long grid, duplicate lists, no outcomes; all work at same weight.

**Actions:**

- [ ] Home: **3–5 featured projects** with one-line job-to-be-done + one-line outcome (e.g. Sozu Pay: complex payments → simple, trustworthy merchant UX).
- [ ] Full list: dedicated **Proyectos** page with filters/tags (Fintech, SaaS, etc.).
- [ ] Later: short case-study pages for top 3–5 (phased).

---

## 6. Lead gen & conversion

**Current gap:** Strong calendar; weak qualification; risk of low-quality calls.

**Actions:**

- [ ] Near calendar: **Ideal for** / **Typical projects** bullets (3–4 lines).
- [ ] Add **intake before or linked from calendar**: product URL, goals (3–6 months), budget range; unify main CTAs to this flow.
- [ ] Optional: **who it’s not for** to filter misfit leads.

---

## 7. Copycraft, i18n & QA

**Actions:**

- [ ] Verify no production CSS/text bugs (words jammed together); fix if present in browser.
- [ ] Resolve “0 años / 0 proyectos” vs dated credibility.
- [ ] **Language strategy:** Decide default (EN vs ES) for global founders; keep bilingual quality equal if both stay prominent.

---

## Synthesis — success criteria

The site should read as a **focused, opinionated boutique** for ambitious founders: 3–4 offers, curated proof, narrative around clarity, conversion, and craft—without a full visual redesign if copy and structure carry the change.

---

## Implementation notes (for dev)

- Prioritize: hero + services/offers + stats + featured portfolio + lead flow.
- Defer: full case-study subsite until core pages match the model.
